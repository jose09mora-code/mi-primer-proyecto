# Mi primer proyecto

Mi primer proyecto para aprender GitHub, HTML, CSS, JavaScript y herramientas de IA.

## Estructura

- `index.html`: estructura principal de la página.
- `css/estilos.css`: estilos y diseño adaptable a móviles.
- `js/app.js`: comportamiento del botón.
- `hola.html`: primera versión del proyecto, conservada como ejemplo.

## Qué estoy aprendiendo

- Cómo organizar una web separando HTML, CSS y JavaScript.
- Cómo guardar cambios en GitHub.
- Cómo publicar una página con GitHub Pages.
